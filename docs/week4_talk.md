# 第 4 周 3 分钟口述

问题：语言条件策略按顺序学新技能时，旧技能成功率会掉。

设定：BabyAI 两个技能，goto 再 pickup。画面 + 英文指令，冻住编码器，只训后面的动作头。行为克隆。两种练法：接着训；每个旧技能只留 2% 轨迹混进新技能训练集。

怎么读主图：横轴是刚学完哪个技能，纵轴是 goto 成功率。学完 pickup 之后，回放线应高于接着训。那就是遗忘被压住了。

三个数：当前技能成功率（新的学会了没）、平均成功率（到现在整体怎样）、遗忘（旧技能历史上最高减去现在）。

边界：格子世界，不是 LIBERO，没有复现某篇 VLA 论文。只是在能训练的语言条件策略上，按同样协议看回放有没有用。
